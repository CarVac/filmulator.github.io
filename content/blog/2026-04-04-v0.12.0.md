Now announcing Filmulator 0.12.0!

# Headline Features

* macOS Arm64 builds
* Noise Reduction
* Highlight Crosstalk: controlled desaturation of extremely bright saturated colors

# Other Features

## Filmulation

* Fix black level on many Panasonic cameras
* When beginning cropping when the image is scaled to fit, it will zoom out a bit to show the top and bottom crop handles.
* Add an explanation that you can zoom in or out by scrolling, and that you can pan around.
* Make sampling a custom white balance not automatically store it.
* If no matching lenses are found, instruct the user to download lens corrections in Settings.
* Fix behavior when camconst.json has not been downloaded.
* Fix white balance completely failing on 26MP Fuji X cameras in extreme circumstances.
* Fix white levels for extended low ISOs.
* Fix monochrome raw handling.
* Properly hide tools that should be unavailable depending on raw type.
* Fix raw histogram scale not being properly cached.
* Adjust range of exposure compensation.
* Make tool sliders show their default with a bold dot; color weights in the monochrome conversion also have 0 and 1 marked.
* Fix Lensfun loading.
* Fix crop edge drags (hold ctrl, drag in, release ctrl, drag out).

## Import

* Make it possible to import from symlinked folders and files.

## Queue

* Fix bug that blocked rating changes when switching image via keyboard.

## General

* Add help button that makes the explanatory tooltips appear immediately throughout Filmulator.
* Fix a few broken tooltips.
* Fix tooltips running off the bottom of the window.
* Make settings reset to their defaults instead of their previous values.
* Make a reset all button in the Settings tab in case the scale got screwed up.
* For any continuous slider, add an explanation to the tooltip for how to open the precise input dial.
